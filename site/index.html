常见问题

激活码如何绑定？

购买后你会收到形如 FH-PRO-XXXX-XXXX-XXXX 的激活码，在应用「关于」页粘贴激活即可。支持在本机自助注销。

可以自己写显示内容吗？

可以。只要能打印到 stdout 的语言都行；也可以直接内嵌 HTML 片段或请求 HTTP 接口。

会收集我的数据吗？

不会。FloatHUD 不联网上报任何信息；数据源是你自己配置的命令或接口。
